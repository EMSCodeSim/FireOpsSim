Recognition

Hazard class reference for training.

This is a quick recognition aid. Use current ERG, SDS, shipping papers, facility information, and HazMat specialists for incident decisions.

ClassGeneral categoryTraining reminder
1ExplosivesExtreme caution, isolation, evacuation, and specialist support.
2GasesCompressed, liquefied, flammable, toxic, or oxygen-displacing hazards.
3Flammable liquidsIgnition control, vapor travel, foam/water runoff considerations.
4Flammable solids / reactive materialsMay react with water, friction, air, or heat.
5Oxidizers / organic peroxidesCan intensify fire and react with contaminants.
6Poison / infectious substancesToxic exposure, contamination control, PPE and decon planning.
7Radioactive materialsTime, distance, shielding, monitoring, and specialist notification.
8CorrosivesSkin/eye/respiratory damage; runoff and container compatibility.
9Miscellaneous dangerous goodsReview shipping papers/SDS/ERG for specific hazard.

Recognition inputs

  • Placard or label
  • UN/NA number
  • Container shape
  • Facility/vehicle type
  • Shipping papers or SDS
  • Smoke/vapor/cloud behavior
  • Victim signs/symptoms and exposure route
