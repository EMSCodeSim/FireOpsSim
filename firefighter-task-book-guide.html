Career Task Book

Use a firefighter Task Book to turn a future position into work you can do today.

Break the goal into requirements, then break each requirement into Learn → Practice → Record actions.

Task Book structure

  • Target role or qualification.
  • Required certifications and department requirements.
  • Preparation tasks for each requirement.
  • Practice and experience evidence.
  • Official verification kept separate from self-completed preparation.
